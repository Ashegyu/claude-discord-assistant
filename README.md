# claude-assistant — 디스코드 개인 비서

디스코드에서 말을 걸면 Claude가 메일·일정·할 일·지출·개발·조사·생활 정보를 대신 처리해 주는 개인 비서예요. 무료 클라우드 VM 한 대에서 24시간 돌고, 비용은 Claude API 사용량뿐이에요(기본 월 100달러 상한).

## Claude에게 설치·사용법 안내받기

아래 프롬프트를 Claude(claude.ai)에 붙여 넣으면 설치 방법과 사용 방법을 한 단계씩 안내받을 수 있어요. 저장소가 비공개라면 Claude가 직접 읽지 못하니 `README.md`, `docs/setup-guide.md`, `docs/usage.md` 세 파일을 함께 첨부하세요.

```text
너는 "claude-assistant"(디스코드 개인 비서) 설치와 사용을 도와주는 안내자야.
기준 문서는 README.md, docs/setup-guide.md(설치 가이드), docs/usage.md(사용법)이야.
첨부한 파일이 있으면 그걸 읽고, 없으면 저장소 https://github.com/Ashegyu/claude-discord-assistant 에서 읽어.
문서를 읽을 수 없으면 기억으로 추측하지 말고, 세 파일을 첨부해 달라고 먼저 말해 줘.

진행 방식
1. 시작하기 전에 세 가지를 물어봐.
   - 쓰고 싶은 기능 (1~5단계는 필수, 6~13단계는 Gmail·구글·To Do·Notion·카카오·Pages·공공데이터·결제 문자 중 선택)
   - 내 PC 운영체제 (Windows / macOS / Linux)
   - 내 폰 (안드로이드 / 아이폰)
2. 답에 맞춰 내가 할 단계 목록과 단계마다 걸리는 대략의 시간을 먼저 보여 줘.
3. 한 번에 한 단계만 설명해. 각 단계는 이 순서로:
   ① 이 단계에서 무엇을 왜 하는지 한두 문장
   ② 어느 사이트·화면에서 무엇을 누르는지 번호 순서
   ③ 복사해서 실행할 명령 (어디서 실행하는지: 내 PC / VM / 디스코드)
   ④ 성공하면 보이는 것
   내가 "됐어"라고 하면 다음 단계로 가.
4. 내가 오류 메시지나 화면 내용을 붙이면, 설치 가이드의 문제 해결 표부터 확인해서 원인과 해결 방법을 알려 줘.
5. 설치가 끝나면 사용법 문서를 바탕으로 자주 쓰는 기능 5가지를 골라, 디스코드에서 직접 한 번씩 해 보게 안내해 줘.
6. 이후에는 내가 "○○ 어떻게 써?"라고 물으면 사용법 문서의 해당 부분으로 답해 줘.

지켜 줄 것
- API 키, 토큰, 비밀번호, 웹후크 주소를 채팅에 붙여 넣으라고 하지 마. 값을 넣는 곳(VM의 .env, GitHub Secrets, 폰 앱)만 알려 줘.
  내가 실수로 붙여 넣으면 그 값을 바로 재발급하라고 알려 줘.
- 문서에 없는 메뉴 이름이나 화면은 "문서에 없어서 확인이 필요하다"고 밝혀.
- 유료 전환이나 결제가 필요한 선택지가 나오면 미리 알려 줘. 이 비서는 무료 범위 안에서 설치하는 게 기본이야.
- 한국어로, 짧은 문장으로, 서버를 처음 다뤄 보는 사람도 따라 할 수 있게 설명해.
```

## 할 수 있는 것

| 분야 | 예시 |
| --- | --- |
| 메일 (Gmail, 읽기 전용) | 중요한 메일만 바로 알림, 하루치 요약, 납부·마감 메일에서 할 일·일정 만들기, 답장 초안 |
| 일정·할 일 | 구글 캘린더 조회·추가, 갤럭시 삼성 리마인더와 연동된 할 일, 아침 브리핑, 장소 있는 일정의 출발 알림(대중교통·자동차) |
| 돈 | 영수증 사진·결제 문자·한 줄 입력으로 Notion 지출 기록, 주간·월간 리포트, 기프티콘 보관 |
| 읽을거리 | 링크만 보내면 요약해서 "나중에 읽기"에 저장, PDF 서재에 올리고 쪽 번호와 함께 질문, 독서 기록 |
| 개발 | GitHub 커밋·diff·이슈·워크플로, 프로젝트별 스레드, AI 플레이테스터 |
| 생활 | 날씨·미세먼지, 장소·후기 검색, 카톡 나에게 보내기, 약속 카드·중간 지점 찾기, 생활 주기(필터 교체 등), 생일 |
| 스스로 관리 | 비용 상한과 절약 모드, 토큰 재발급 알림, 주간 자기 개선 PR, 구글 드라이브 백업, 생존 감시 |

사진만 보내도 종류(일정·영수증·기프티콘·택배 등)를 알아보고 알맞은 버튼을 띄워요. 사용 예는 [사용법](docs/usage.md)에 있어요.

## 구조

```
디스코드 메시지 (텍스트·사진·파일)
   │
   ▼
① 라우터 (Haiku) ─ 간단/복잡 분류
   │
   ├─ quick ─▶ ② 지휘자 Haiku + Opus 어드바이저
   └─ deep  ─▶ ② 지휘자 Sonnet + Opus 어드바이저
                  │  delegate(agent, task) — 여러 개 동시 호출
                  ▼
        ③ 전문 에이전트 (각자 자기 도구만 가짐)
           mail · schedule · dev · research · life
                  │
                  ▼  대량·비긴급 작업
        ④ Message Batches (50% 할인) → 끝나면 결과를 디스코드로

백그라운드: 메일 감시 · 리마인더 · 출발 알림 · 아침 브리핑 · 리포트 · 백업 · 재발급 점검
```

| 설계 포인트 | 내용 |
| --- | --- |
| 어드바이저 | 실행은 싼 모델(Haiku·Sonnet)이 하고, 계획·막힘 순간에만 Opus에게 조언을 받아요. 턴당 사용 횟수를 제한해요 |
| 프롬프트 캐싱 | 도구 정의와 시스템 프롬프트 고정부는 1시간, 대화는 5분 캐시. 비용의 대부분을 줄여요 |
| 배치 | 커밋 여러 개 요약, 야간 메일 요약 같은 일은 Message Batches로 보내 반값에 처리해요 |
| 서재 | PDF를 쪽별 텍스트로 저장하고, 질문하면 관련 쪽만 골라 읽어 쪽 번호와 원문 인용으로 답해요 |
| 설정 분리 | 기본값은 `config.yaml`(저장소), 내 값은 VM의 `config.local.yaml`(디스코드 `!set`). 업데이트가 충돌하지 않아요 |

## 안전장치

- 디스코드 소유자 ID 한 명에게만 응답해요.
- 일정 추가, 이슈 생성, 워크플로 실행, 카톡 전송, Notion 쓰기 같은 바깥에 영향을 주는 일은 **[실행]/[취소] 버튼**을 누른 뒤에만 해요.
- Gmail은 읽기 전용이에요. 읽음 표시도 바꾸지 않고, 답장은 초안만 만들어요.
- 비밀값은 VM의 `.env`·`data/`(Git 제외), GitHub Secrets, 폰 앱 안에만 있어요. 백업에도 들어가지 않아요.
- 자기 개선 PR은 고칠 수 있는 파일이 정해져 있고, 자동으로 병합하지 않아요.
- 결제 문자 전달 앱은 메시지 앱 알림 중 카드 결제 문자만 내보내고, 비서는 그 글을 지출 기록에만 써요.

## 개발

```
assistant/        비서 본체 (bot.py가 시작점, tools/에 에이전트 도구)
deploy/           VM 설치 스크립트, 구글·MS·카카오 로그인 스크립트, 백업 복구
site/             GitHub Pages로 게시되는 웹 카드·대시보드
android/          결제 문자 전달 앱 (Actions가 APK 빌드)
playtest/         AI 플레이테스터 (Actions에서 실행)
docs/             설치 가이드, 사용법
tests/            오프라인 테스트 (실제 API 없이 가짜 클라이언트로 전체 흐름 검증)
```

```bash
python -m pytest -q tests/
```

코드를 고치면 GitHub Actions가 테스트를 돌리고, VM에서는 디스코드 `!update`로 받아 재시작해요. 사용법 문서에 적은 `!명령`이 실제로 있는지도 테스트가 확인하니, 명령을 바꾸면 [docs/usage.md](docs/usage.md)도 같이 고쳐 주세요.
